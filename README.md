# Stiker Ajaib: Adjective Puzzle Adventure

![Stiker Ajaib](thumbnail.png)

Gim edukasi Bahasa Inggris SD tentang kata sifat (*Adjectives to Describe Things*). Tempelkan stiker kata sifat pada benda untuk menolong Kiko, lalu susun frasa dan kalimat bahasa Inggris seperti *a long ladder* dan *The ladder is long*.

Mainkan: https://stikerajaib.klikajar.com/
